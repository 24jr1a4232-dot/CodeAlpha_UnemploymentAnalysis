# CodeAlpha_UnemploymentAnalysis
📊 Unemployment Analysis with Python
---

**📌 Objective**

Analyze unemployment trends and study the impact of COVID-19 on employment rates.

---

**📊 Dataset**

The dataset contains unemployment rate data across regions and time periods.

---

**🛠️ Tools Used**
- Python
- pandas
- matplotlib
- seaborn

---

**⚙️ Methodology**
- Loaded dataset
- Cleaned missing values
- Performed exploratory data analysis (EDA)
- Visualized unemployment trends over time
- Analyzed regional variations
- Studied COVID-19 impact on unemployment

---

**📈 Results**

The analysis shows clear variations in unemployment rates over time, especially during the COVID-19 period.
